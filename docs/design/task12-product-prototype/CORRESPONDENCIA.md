## Estados, datos y límites técnicos

| Tema                                                                          | Simulación                                                                                                                      | Consecuencia para una implementación futura                                                                                                                                               |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Colecciones completas de rutas, asignaciones, pagos y contactos del conductor | Búsqueda/filtros y páginas sobre arrays en memoria.                                                                             | Los endpoints actuales descritos en el lote de recuperación no tienen paginación del servidor. El prototipo **no acredita escalabilidad de transferencia** ni autoriza parámetros nuevos. |
| Colas administrativas y soporte                                               | Todos los datos de muestra están en memoria; se presentan por páginas.                                                          | Conservar paginación autenticada, filtros, orden y límites reales de cada recurso. No sustituirla por descarga completa.                                                                  |
| Capacidad                                                                     | Derivada de asignaciones sintéticas vigentes para el 04 nov; no de la página visible. Conflicto local para la fecha de muestra. | La API es autoridad de capacidad y fecha en producción. El prototipo no implementa validación de todos los solapamientos futuros ni conflictos de ejecución.                              |
| Montos                                                                        | Suma de registros sintéticos por estado; filtro por período del servicio.                                                       | Mantener naturaleza manual y alcance de agregados. Nunca convertir «registrado pagado» en «verificado por banco».                                                                         |
| Lecturas fallidas / carga                                                     | Estados detenidos seleccionables; reintento local termina con datos.                                                            | No demuestra timeout, red ni disponibilidad reales. Desconocido no se representa como cero.                                                                                               |
| Resultado incierto de recorrido                                               | Inicio no aparece hasta consultar estado; recuperación determina En curso.                                                      | Conservar el control real de duplicados, conflictos y respuesta tardía de Flutter.                                                                                                        |
| Documento / mapas / Excel / legal / ingreso                                   | Muestras explicadas; sin archivos personales, descarga Excel, app externa o autenticación.                                      | Mantener integración, privacidad y validación reales cuando se implemente un diseño aprobado.                                                                                             |
| Historial, permisos, consentimiento                                           | Ejemplos en memoria para revisar la composición y decisiones.                                                                   | No reemplazan auditoría, control de versiones, propiedad, roles ni autorizaciones del servidor.                                                                                           |
| Android                                                                       | HTML con patrones Material 3 y dimensiones de referencia.                                                                       | No demuestra TalkBack, fuente nativa, teclado físico, botón Atrás del sistema, gestos ni comportamiento Samsung. Se revisa en Flutter después de una autorización de implementación.      |

## Decisiones que quedan para revisión humana

La navegación de detalles del recorrido/manifiesto, el equilibrio de densidad, el panel contiguo de rutas, las filas por página y el comparador móvil son **propuestas**, no cambios aprobados para producción. La pauta está en [GUIA.md](GUIA.md). No se trasladan archivos de este prototipo a React/Flutter al cerrar esta entrega.
