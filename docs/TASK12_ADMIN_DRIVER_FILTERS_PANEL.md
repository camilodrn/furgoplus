# T12 · Filtros compactos de Conductores

29-10-2026 · `task/12-plan-capabilities` · **aceptación humana pendiente en Fedora**.

Esta continuación sustituye únicamente la composición del filtrado del listado. La revisión humana aprobó las pestañas y el menú de acciones del detalle administrativo: se conservan íntegros. La grilla desplegada a todo el ancho del listado no fue aprobada; este ajuste reemplaza esa composición.

En escritorio, la barra contiene una búsqueda de hasta 28 rem, Buscar y Filtros. El panel parte cerrado y se superpone bajo el extremo de Filtros, sin desplazar el listado ni su cantidad de resultados. Tiene un ancho máximo de 36 rem, cinco selectores distribuidos en dos columnas y acciones Aplicar filtros, Limpiar y Cerrar. El botón muestra discretamente el número de filtros avanzados **aplicados**; la búsqueda no se cuenta. El total se muestra junto al título, fuera del área que cubre el panel; los criterios aplicados permanecen bajo la barra.

Hasta 700 px, la barra dispone la búsqueda sobre los dos botones y el panel pasa al flujo normal con una columna. A 420 px o menos, sus acciones ocupan filas completas. Los controles mantienen el tamaño y foco del sistema (mínimo 48 px); el contenido crece naturalmente, sin alturas fijas, recortes, scroll interno ni ocultación del desborde.

| Acción                                           | Resultado                                                                                                                                                                                                     |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Buscar o Enter en búsqueda                       | Envía `q` a la API con los filtros avanzados ya aplicados; vuelve a la primera página. No incorpora borradores avanzados cerrados.                                                                            |
| Abrir Filtros                                    | Enfoca el primer selector. El panel no modal tiene nombre, descripción y relación con el botón. Tab y Shift+Tab recorren controles nativos; salir del panel hacia otro control lo cierra sin retener el foco. |
| Cambiar un selector                              | Solo cambia el borrador; aparece «Cambios sin aplicar». No consulta la API.                                                                                                                                   |
| Aplicar filtros o enviar el formulario del panel | Envía búsqueda y filtros del borrador, reinicia la paginación, cierra y devuelve el foco a Filtros.                                                                                                           |
| Limpiar, dentro del panel                        | Restablece los cinco selectores del borrador, conservando la búsqueda. Requiere Aplicar filtros para cambiar resultados.                                                                                      |
| Cerrar, Escape o volver a pulsar Filtros         | Cierra y devuelve el foco al botón; conserva el borrador sin aplicarlo.                                                                                                                                       |
| Pulsar fuera                                     | Cierra sin aplicar ni borrar; respeta el foco del control elegido.                                                                                                                                            |
| Limpiar filtros, junto a criterios               | Conserva el comportamiento anterior: borra búsqueda, borrador y criterios aplicados, consulta la primera página completa y enfoca la búsqueda.                                                                |
| Paginar o volver del detalle                     | Mantiene criterios aplicados, borrador y lógica de lecturas del listado.                                                                                                                                      |
